Built for Scale & Resilience

Designed to handle erratic mobile networks, high concurrency, and horizontal cluster scaling.

📡

Redis Pub/Sub Fan-Out

Transparent cross-replica routing. Persist to MongoDB once, publish to Redis, and automatically broadcast across all active nodes.

⏱️

TTL Presence Engine

30s client heartbeats with 60s Redis TTL. Automatic Redis keyspace expiry detection guarantees accurate offline presence.

🛡️

Intelligent Backpressure

Bounded buffers safely drop non-critical presence telemetry under slow network links while preserving 100% of chat messages.

🔔

Firebase FCM Push

Intelligent offline notification engine with 30-second conversation anti-spam batching and automatic stale token pruning.

⚖️

SME Quotas & Guardrails

Redis sliding-window rate limiters enforce 20 msg/min and 5 conversations/day to prevent network abuse and runaway costs.

🪣

MinIO S3 Attachments

Reactive multipart upload streaming for invoices, receipts, and product images up to 25 MB with S3-compatible cloud storage.

Simple, Production-Ready Deployment

Run 2 application replicas behind Nginx with one Docker Compose command.

# Clone and start full cluster with load balancer git clone https://github.com/crnjihia/relay-messaging.git cd relay-messaging docker compose up -d --build # Verify health across both replicas curl http://localhost:8080/actuator/health {"status":"UP"}
